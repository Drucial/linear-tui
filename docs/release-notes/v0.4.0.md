This release adds a Windows installer, an upgrade command, and pictures in
issue descriptions.

## New

**Windows installs in one line.** `install.ps1` is `install.sh` for Windows,
arm64 and amd64, with the same checksum gate. The binary lands in
`%LOCALAPPDATA%\Programs\zen-linear`. An upgrade renames the running copy aside
first, since Windows will not overwrite a binary in use.

**`zen-linear update` upgrades in place.** It runs the same installer a fresh
install runs, pointed at the directory the binary is already in. Quit the app
first. `zen-linear help` lists the commands.

**Pictures draw in the description.** A PNG in an issue's description is drawn
where it sits, scrolls with the page, and keeps its name underneath. It needs a
terminal that speaks the Kitty graphics protocol, which Ghostty, Kitty, WezTerm
and recent Konsole all do. zen-linear asks the terminal at launch rather than
reading `TERM`. Everywhere else the name and the link appear, as before. Set
`images` to `off` for that everywhere.

**The status bar says when a newer release is out.** Checked once a day. The
request carries the running version and nothing else, and nothing is
downloaded. `update_check` set to `false` turns it off, and a binary you built
yourself is never checked.

## Fixed

**Saving a setting keeps your place.** A save used to reload the workspace, so
you lost the list you were on, your filters, and everything already fetched.
Now it applies what changed. The token, the endpoint and the timeout still
reload, since those move the connection itself.

**A rate limit waits rather than fails.** Linear reports one as a 400 rather
than a 429, so it read as an error and the request died. It now waits out the
window the response names, then retries. Writes are never resent.

## Changed

**An unrecognized command prints usage.** `zen-linear nope` used to launch the
app. It now prints the command list and exits 1.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/praxis-labs-io/zen-linear/main/install.sh | sh
```

macOS or Linux, on arm64 or amd64. Windows:

```powershell
irm https://raw.githubusercontent.com/praxis-labs-io/zen-linear/main/install.ps1 | iex
```

Already running zen-linear: `zen-linear update`.

On macOS and Linux the binary lands in `~/.local/bin`, which some shells do not
carry on PATH. The installer says so if yours does not.

The tree's icons need a [Nerd Font](https://www.nerdfonts.com). Without one
they draw as empty boxes, and nothing else depends on it.
